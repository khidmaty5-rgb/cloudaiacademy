# Academy role, navigation and security rollout

User authorized implementation and deployment on 2026-10-13. This release
integrates the previously tested local security/role batches; it is not a claim
that every roadmap item or real-role acceptance test is finished.

## Spark-only constraint — latest checkpoint

User requires free plans only. The earlier Blaze worker requirement is REMOVED:
no Functions deployment, paid scheduler or billing upgrade is needed by the active
role workflows. Account creation goes directly through the existing Next API;
profile edits do not reassert role or trigger Functions. Removed the newly added
audit worker and unused Cloud Functions CSP origins/emulator connection.

Explicit administrator recovery is available in People and /api/admin/role-sync:
list up to 20 pending audits, retry current authoritative role, preserve other
claims, mark successful sync; Auth/read/race failures stay pending. Existing
user self-sync and profile-authoritative permissions remain. Recovery is manual
or user-session-driven, NOT guaranteed offline automatic delivery. Legacy optional
Functions source is retained/tested but is not required or deployed.

Validation: build exit0/compile30.2s, typecheck/targeted lint pass, 136 broad tests
pass/four optional skips, 14 transaction/query/recovery emulator tests pass.
No new paid infrastructure or cloud data migration. Existing provider quotas,
storage and AI integrations still require their own free allowance/eligibility;
this is not a promise of unlimited free usage or an audit of every provider's bill.
Earlier billing-blocked attempts below are historical, not current prerequisites.
Production-rule deployment approval remains an independent release gate.
