# Academy role, navigation and security rollout

User authorized implementation and deployment on 2026-10-13. This release
integrates the previously tested local security/role batches; it is not a claim
that every roadmap item or real-role acceptance test is finished.

## Included

- Capability-derived contextual menu with bilingual workspace switcher, desktop
  and mobile navigation, route-derived direct-link selection and shared tools.
- Zero-specificity content defaults: explicit form max-width utilities work again.
- People directory loads at most 51 records (50 visible + next-page sentinel),
  stable join-date/document-ID cursor, previous/next, explicit page-local search.
  Counts are page counts, not misleading academy totals. Server-side global search
  and role-filter indexes are follow-up work, not silently emulated locally.
- Role confirmations display identity, transition and privilege summary; cancellation
  makes no request, self-changes disabled, server rejection remains visible for retry.
- Missing Arabic review dialogs/options/placeholders and course management labels.
- Canonical role validation, profile-authoritative callable/guards/rules,
  transactional role changes, last-admin demotion controls, server audit and retry.
- Nonce CSP Report-Only rollout, enforced clickjacking/object/base baseline,
  nosniff/referrer/permissions headers, escaped JSON-LD and bounded chart CSS sinks.
- Literal credential discovery paths fix production build tracing. No credentials
  copied into source. HSTS remains owned by Vercel.
- Functions target supported Node22; removed unused parent-application file
  dependency (no Functions source imports it), making the deployment standalone.

## Verified locally

- Production build: exit0, compile31.3s; bundled lint/type checks pass (existing warnings).
- TypeScript passes; changed UI lint zero errors; Functions lint/build pass.
- 132 non-emulator tests pass; four optional skips. Includes actual React/Radix
  browser menus for five mocked roles, English/Arabic, 390px/1440px, role confirmation.
- 57 emulator policy/rules tests and 12 transaction/query/pagination tests pass.
- Built-server Report-Only nonce/header/startup/signed-out smoke: two pass,
  enforcement-only case intentionally skipped in this mode.

## Explicit remaining gates

Full CSP enforcement requires independent interactive-content hosting plus actual
stored S3/embed origin inventory. Do not set CSP_MODE=enforce in this rollout.
Real staging sign-ins, payment/live-provider/restore acceptance remain unverified.
Teaching/editorial namespace migration and duplicate teacher-dashboard consolidation
must preserve metrics/bookmarks; not part of this release. Shared PageHeader/page
width component migration, global directory search, audit-viewer and controlled
account-deletion/recovery workflows remain tracked in ROLES_LAYOUT_TASKS.md.

Production deployment and backend release results will be recorded separately
after CI and cloud deployment complete. No existing user/course data is migrated.
