# **App Name**: CloudWise Academy

## Core Features:

- AI-Powered Course Recommendations: Suggest courses to users based on their learning history and career goals, using a tool that incorporates the most in-demand skills for AI and cloud computing jobs.
- Personalized Learning Paths: Generate custom learning paths tailored to individual student needs and interests.
- Progress Tracking: Visualize learning progress and achievements.
- Course Catalog: Browse a comprehensive catalog of cloud and AI courses.
- User Authentication: Secure user login and registration.

## Style Guidelines:

- Primary color: Deep blue (#29434e) for a professional and trustworthy feel.
- Background color: Light gray (#f0f2f5) for a clean and modern look.
- Accent color: Orange (#f0711b) to highlight calls to action and important information.
- Headline font: 'Space Grotesk', sans-serif, for a techy, modern look.
- Body font: 'Inter', sans-serif, for readability and a clean aesthetic.
- Use minimalist, consistent icons to represent course categories and features.
- Ensure a clear and intuitive layout with a focus on easy navigation and readability.
- Incorporate subtle animations for a smooth user experience.
